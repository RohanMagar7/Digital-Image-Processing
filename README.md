# Digital-Image-Processing

A collection of practical implementations and code examples for performing various digital image processing techniques. This repository is designed to help understand and apply image processing concepts effectively.

```

---

## 🚀 Features

1. **Image Filtering**
   - Implementations of Gaussian, Median, and other filters.
   - Example: `gaussian_naruto.jpg`.

2. **Image Compression**
   - Techniques for compressing images without significant quality loss.
   - Example: `compressed_naruto.jpg`.

3. **Basic Image Transformations**
   - Resizing, rotating, and cropping images.
   - Conversion between color spaces (RGB, Grayscale).

4. **Edge Detection**
   - Applying Sobel, Prewitt, and Canny edge detection techniques.

---

## 📖 Prerequisites

Ensure you have the following installed:
- **Python 3.x**
- Required Python libraries:
  - `numpy`
  - `opencv-python`
  - `matplotlib`

Install dependencies using:
```bash
pip install -r requirements.txt
```

## 📂 How to Use

1. Clone this repository:
   ```bash
   git clone https://github.com/RohanMagar7/Digital-Image-Processing.git
   ```
2. Navigate to the `pratical` folder:
   ```bash
   cd Digital-Image-Processing/pratical
   ```
3. Run any script:
   ```bash
   python [script_name].py
   ```
